## 🎯 Обзор

`f-insight` объединяет в себе real-time аналитику лобби матчей FACEIT, продвинутую систему выявления смурфов (Red Flags), автоматизацию матчмейкинга (авто-принятие матчей, быстрое копирование IP сервера), точный расчет ставок Elo за победу/поражение и оценку огневой мощи команды (FCR) в едином, быстром и **полностью автономном (Zero-Config)** расширении.

## ✨ Ключевые возможности

### 1. ⚡ Автоматизация матчмейкинга и QoL
- **Auto Ready-Up**: Автоматически нажимает кнопку «ACCEPT» / «READY» при нахождении матча.
- **Auto-Accept Party Invites**: Автоматически принимает приглашения в лобби от друзей.
- **Подключение к серверу в 1 клик**: Мгновенное копирование команды `connect <ip:port>` в буфер обмена и кнопка прямого запуска через `steam://connect`.
- **Звуковой сигнал**: Приятный звуковой сигнал (Web Audio Chime) при готовности и настройке игрового сервера.
- **Точный расчет ставок Elo (+/-)**: Отображение реального выигрыша и проигрыша очков (например, `+24 / -26 ELO`) для каждой команды.

### 2. 🔮 Тактическая аналитика и показатели формы
- **FCR (Firepower Contribution Rating)**: Процентная доля огневой мощи и импакта каждого игрока в команде (сумма 5 игроков = 100%, >25% указывает на явного Star Carry).
- **Индикатор текущей формы (Player Form & Momentum)**:
  - 🔥 **ON FIRE**: Игрок на пике формы (K/D и ADR за последние 5 матчей на > +15% выше среднего).
  - 🧊 **COLD / TILT**: Спад в последних играх.
  - ⚖️ **STABLE**: Стабильная игра.
- **ADR (Average Damage per Round)**: Вычисление и отображение среднего урона за раунд в карточках игроков и профиле.
- **Тактическая матрица мап-пула (Veto Helper)**: Сравнение винрейтов и K/D обеих команд на всех 7 картах со статусом преимуществ и рекомендациями по пикам/банам.

### 3. 🚨 Детектор смурфов и Red Flags (0–100%)
- **Взвешенный скоринг рисков**: Подсветка аккаунтов с малым числом матчей и высоким Elo, аномальными винрейтами (>70%) и всплесками K/D.
- **Аудит профиля Steam**: Проверка часов в CS2, возраста аккаунта, банов VAC/Game и корректная обработка скрытых профилей `[Private Steam]`.
- **Определение пати и стаков**: Автоматическая группировка и цветовая маркировка игроков в очереди (`Party A`, `Party B`).

### 4. 🎨 Zero-Config и изоляция через Shadow DOM
- **100% Zero-Config**: Работает «из коробки» без необходимости регистрировать API-ключи разработчика.
- **Изоляция Shadow DOM**: Все стили изолированы, что гарантирует отсутствие конфликтов и наложений на оригинальный интерфейс FACEIT.

## 🚀 Установка и быстрый старт

1. Склонируйте или скачайте репозиторий:
   ```bash
   git clone https://github.com/m0rvey/f-insight.git
   cd f-insight
   ```
2. Установите зависимости и соберите проект:
   ```bash
   npm install
   npm run build
   ```
3. Откройте Chrome / Brave / Edge / Яндекс.Браузер и перейдите в `chrome://extensions/`.
4. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
5. Нажмите кнопку **Загрузить распакованное** (*Load unpacked*) и выберите папку `f-insight/dist`.
6. Откройте любую комнату матча на FACEIT: `https://www.faceit.com/ru/cs2/room/...`

## 🛡️ Безопасность и правила FACEIT

- ✅ **Безопасно и Read-Only**: Расширение не внедряется в процесс игры, не перехватывает сетевые пакеты и не нарушает ToS платформы.
- ⚙️ **Гибкая настройка**: Авто-принятие матчей и звуковые оповещения можно включить или выключить в любой момент во всплывающем окне расширения.
- 🔒 **Приватность данных**: Все кэшированные данные хранятся локально на вашем устройстве в `chrome.storage.local`.
