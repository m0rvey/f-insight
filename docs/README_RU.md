## 🎯 Обзор

`f-insight` объединяет в себе real-time аналитику комнат матчей FACEIT, многофакторный прогноз исхода матча с симуляцией счета MR12, выявление смурфов (Red Flags), автоматизацию матчмейкинга (авто-принятие матчей, быстрое копирование IP сервера), точный расчет ставок Elo и оценку огневой мощи команды (FCR) в едином, быстром и **на 100% автономном (Zero-Config)** расширении.

## ✨ Ключевые возможности

### 1. ⚡ Автоматизация матчмейкинга и QoL
- **Auto Ready-Up**: Автоматически нажимает кнопку «ACCEPT» / «READY» при нахождении матча.
- **Auto AFK Inactivity Dismiss**: Автоматически подтверждает проверки на AFK («Вы еще здесь?»), предотвращая вылет из поиска.
- **Auto-Continue Match Queuing**: Автоматически возобновляет поиск, если кто-то из игроков не нажал Ready.
- **Auto-Dismiss Captain Notices**: Автоматически закрывает модальные окна выбора капитана и монетки.
- **Clean Interface (Hide Banners)**: Скрывает навязчивые баннеры скачивания десктопного клиента FACEIT.
- **Подключение к серверу в 1 клик**: Мгновенное копирование команды `connect <ip:port>` в буфер обмена и кнопка прямого запуска через `steam://connect`.
- **Точный расчет ставок Elo (+/-)**: Отображение реального выигрыша и проигрыша очков (например, `+21 / -29 ELO`) для каждой команды.

### 2. 🧠 Многофакторный прогноз и тактическая аналитика
- **Многофакторный предикт CS2**: Расчет вероятности победы с учетом базового Elo, опыта на выбранной карте ($\pm 12\%$), моментума и формы игроков ($\pm 10\%$) и сыгранности пати/стаков ($\pm 8\%$).
- **Симуляция итогового счета MR12**: Расчет вероятного счета (например, `13 : 9` или `13 : 11 (OT Likely)`).
- **Map Veto & Action Plan**: Полная матрица пула карт CS2 (включая Cache, Train, Overpass) с ключевыми ориентирами для капитана (**Priority 1: Best Pick** и **Priority 1: Must Ban**).
- **Показатель Top Map**: Отображение лучшей карты команды в основном блоке сравнения рядом с Avg Elo, Avg K/D, Avg ADR и Avg HS%.
- **FCR (Firepower Contribution Rating)**: Процентная доля огневой мощи каждого игрока в команде (сумма 5 игроков = 100%, >25% указывает на явного Star Carry).

### 3. 🎴 Радар навыков, Elo прогресс-бар и история
- **5-осевой Радар навыков (Spider Chart)**: Чистый SVG-радар по ключевым характеристикам: **Firepower** (K/D), **Damage** (ADR), **Precision** (HS%), **Winrate** и **Impact** (FCR/Form).
- **CS2 Level & Elo Progress Bar**: Прогресс-бар до следующего уровня (1–10) с точным числом очков до Level Up (`+45 ELO to Level 10`) и предупреждением о буфере защиты от понижения.
- **Дельта +/- ELO в истории матчей**: Цветные плашки изменения рейтинга (`+25` / `-24`) прямо в списке недавних игр с итоговым блоком **Net ELO**.
- **Индикатор «Hidden account»**: Корректное выделение скрытых и приватных профилей Steam.
- **Серии побед и поражений**: Точный подсчет непрерывного стрика (`🔥 4W` или `🧊 3L`).
- **Индикатор текущей формы**: 🔥 `ON FIRE` (на пике формы) или 🧊 `COLD / TILT` (на спаде).

### 4. 🚨 Детектор смурфов и Red Flags (0–100%)
- **Взвешенный скоринг рисков**: Подсветка аккаунтов с малым числом матчей и высоким Elo, аномальными винрейтами (>70%) и всплесками K/D.
- **Аудит профиля Steam**: Проверка часов в CS2, возраста аккаунта, банов VAC/Game и корректная обработка скрытых профилей `[Private Steam]`.
- **Определение пати и стаков**: Автоматическая группировка и цветовая маркировка игроков в очереди (`Party A`, `Party B`).

### 5. ⌨️ Глобальные горячие клавиши
- `Alt + V` (или `Alt + М`): Быстрое открытие/скрытие матрицы вето карт.
- `Alt + R` (или `Alt + К`): Принудительное мгновенное обновление статистики лобби.
- `Alt + H` (или `Alt + Р`): Скрыть / показать оверлей расширения.

## 🚀 Установка и быстрый старт

1. Склонируйте или скачайте репозиторий:
   ```bash
   git clone https://github.com/m0rvey/f-insight.git
   cd f-insight
   ```
2. Установите зависимости и соберите проект:
   ```bash
   npm install
   npm run build
   ```
3. Откройте Chrome / Brave / Edge / Яндекс.Браузер и перейдите в `chrome://extensions/`.
4. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
5. Нажмите кнопку **Загрузить распакованное** (*Load unpacked*) и выберите папку `f-insight/dist`.
6. Откройте любую комнату матча на FACEIT: `https://www.faceit.com/ru/cs2/room/...`

## 🛡️ Безопасность и правила FACEIT

- ✅ **Безопасно и Read-Only**: Расширение не внедряется в процесс игры, не перехватывает сетевые пакеты и не нарушает ToS платформы.
- ⚙️ **Гибкая настройка**: Авто-принятие матчей и звуковые оповещения можно включить или выключить в любой момент во всплывающем окне расширения.
- 🔒 **Приватность данных**: Все кэшированные данные хранятся локально на вашем устройстве в `chrome.storage.local`.
